ILLUSTRATIVE EXAMPLE. Example instruction shown below.

A water-testing lab counted a bottled mineral water sample on a liquid scintillation counter.
Using the count data in `/app/data/counts.csv` and the Tc-99 standard details in `/app/data/standard.txt`,
determine the counting efficiency, the activity concentration of the sample in Bq/kg, and the
detection limit. Write one value per line to `/app/results.txt` in the order: efficiency, activity,
detection limit. Round each value to three significant figures.
